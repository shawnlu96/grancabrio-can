# grancabrio-can

**2016 款玛莎拉蒂 GranCabrio**（M145，4.7L V8，ZF 6HP26）的 CAN 总线解码。仓库里有：

- 逆向出来的广播帧，整理成 [DBC 文件](dbc/maserati_grancabrio_2016.dbc)；
- 每一路信号的证据和把握；
- 找信号用的方法，以及能直接在真车样本上跑的工具；
- 一个只听不发的 ESP32 实时解码器。

标准 OBD 查询拿不到方向盘转角、四个轮子各自的转速、实际挡位、刹车踏板，这台车连机油温度都不回答。这些车自己都在 OBD 口的总线上广播，但格式厂商不公开。我们没找到这代车公开的解码资料，就把自己整理的放出来。

## 解出来的信号

| 信号 | ID | 把握 |
|---|---|---|
| 方向盘转角（0.1°，正 = 左打），48Hz | `0x0CC` | 实车验证 |
| 车速 | `0x146`、`0x566` | 高，三条互不相干的证据 |
| 四轮转速（1/16 km/h） | `0x166` | 高；前后轮对应关系中高 |
| 转速、发动机负载 | `0x361` | 高 / 中高 |
| 实际接合挡位 | `0x0CB` | 1~4 挡高；倒挡、5、6 挡还没录到 |
| 刹车踏板 | `0x061` | 中高 |
| 水温 | `0x761` | 高 |
| 机油温度 | `0x581` | 约 90% |
| 行程计数（10 米一格） | `0x560` | 高 |

每一路的证据和未解问题见 [docs/signals.md](docs/signals.md)（英文）。

只在一台车上验证过。同代的 GranTurismo / GranCabrio 大概率一样，但还没人核对过。

## 目录

| 目录 | 内容 |
|---|---|
| `dbc/` | 解码表，SavvyCAN、cantools、python-can 等工具都能打开 |
| `docs/` | 信号证据、找信号的方法、接线与供电、ESP32 的坑 |
| `samples/` | 车上录的真实数据（candump 格式）：一段 9 分钟市区行车，一段 29 分钟启动后怠速 |
| `tools/` | 按相关性给字段排名、按升温曲线找温度、按速比分挡位、电脑上录板子的串口 |
| `firmware/` | ESP32-S3 的 ESPHome 配置和 C++ 代码：实时解码、网页、可选的原始帧串口输出、单测和样本回放 |

## 安全

- **只读。** 固件让 CAN 控制器工作在纯监听模式，什么都不发，连应答位都不发。这个项目只记录车在说什么，不教怎么跟车说话。
- **供电。** 从随点火开关断电的 USB 口取电，绝不从 OBD 16 脚（常电）取，否则会亏电瓶。
- **风险自负。** 接线接错可能让车报故障。这是一个车主在一台车上做的东西，按原样提供。

## 其他车型

如果你有同年代的 GranTurismo、GranCabrio 或总裁，从 OBD 口录几分钟 candump 就能知道这些 ID 对不对得上。欢迎开 issue 告诉我们车型、年份，以及一小段录制，或者一句"对得上 / 对不上"。

个人项目，欢迎 issue 和 PR，但不保证答复。
